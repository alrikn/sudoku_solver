# sudoku_solver
I'm decent at sudoku, but once in a while, i get really stuck, and i don't see a path forward. So i'm making a sudoku solver for people like me that are too lazy to get down and dirty and manually calculate the odds of numbers being at a certain spots.


### Usage:

```bash
#compile
make re

#run project
./sudoku_solver puzzles/easy.txt
```

This sudoku solver does not use brute force to find solves, because i believe that any sudoku that requires brute force is boring and uninspired.

### Disclaimer:
This project is not finished, and as such it will not be able to solve any kind of sudoku (yet).
I will also be using this to learn some new sudoku tricks, so if you go in the source code and see some obscure technique name, that might be why.
